# ONE for Mining — Context (Glossary)

The canonical language for the Digitalrain ONE for Mining pitch materials (brochure + deck). A glossary only — no implementation detail, no spec.

## Language

**Decision**:
A recurring operational choice that today is made late or on stale data (e.g. "should we pull mill 3 for maintenance this shift?"). ONE surfaces the recommendation and the supporting evidence; a human commits the action. Decision-making is human-owned in the current product.
_Avoid_: using "decision" to mean an automated action ONE takes on its own (that is roadmap "agentic workflows", not today).

**Execute**:
ONE turns a recommendation into a routed alert and a drafted task assigned to the right person; the person accepts and the action is carried out in the system of record. ONE prompts, it does not act.
_Avoid_: "drives the work" and any phrasing implying ONE writes to or actuates other systems (conflicts with read-only). Preferred line: "ONE puts the right decision in front of the right person, with the evidence, in time to act."

**Live (at Engebø)**:
ONE is in live production use at Engebø, running on Nordic Mining's real plant data, a named, permissioned reference site. "Live/production" attaches to the SOFTWARE (ONE is deployed and operating on real data) — a strong, defensible claim confirmed by Steven.
_Avoid_: (1) letting "live" be confused with the displayed figures (those are masked — see Illustrative); (2) phrasing that implies the MINE has reached commercial production unless separately confirmed. Defensible canonical line: "ONE is in live production at Engebø, running on Nordic Mining's real plant data."

**Illustrative (figures)**:
The Engebø metrics shown are representative stand-ins for real, live data that cannot be displayed due to client data-security/confidentiality restrictions. They are illustrative because the real data is protected — NOT because outcomes are unproven or unaudited.
_Avoid_: "not audited results", which wrongly implies the numbers may be soft or invented. Preferred framing: "real figures, masked for client data security."

**Proof**:
What a prospect can actually verify about ONE: (1) a reference call with Nordic Mining under NDA, and (2) the eight-week diagnostic run on the prospect's own data. Normalized/relative Engebø metrics are offered deal-by-deal where Nordic Mining permits. Proof rests on the reference + the buyer's own data, never on the masked Engebø figures alone.
_Avoid_: equating "proof" with the on-screen Engebø numbers (they are masked and therefore not independently verifiable by the prospect).
