<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Domain proof → storage adapter | Domain supplies only server-derived keys and generated payloads. |
| R2 adapter → provider bucket | Provider failures must remain blocked/unproven. |
| Audit evidence → capability UI | Evidence is minimized and cannot itself authorize effects. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-09 | Tampering | capability evidence | mitigate | Pure projection validates required successful steps and freshness. |
| T-01-10 | Information disclosure | object key/payload | mitigate | Server-derived opaque prefix and random non-sensitive bytes only. |
| T-01-11 | Elevation | object port | mitigate | No caller-supplied workspace, key, or bucket handle. |
| T-01-12 | Repudiation | proof result | mitigate | Minimized immutable audit record includes step outcomes and reference. |
| T-01-13 | Denial of service | probe | mitigate | One fixed small payload, bounded route in Plan 04, cleanup required. |
</threat_model>
