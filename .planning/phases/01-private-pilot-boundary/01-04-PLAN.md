<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → capability APIs | Browser input is untrusted and cannot grant proof or select scope. |
| Capability API → D1/R2 | Admitted workspace context and fixed operation cross provider boundaries. |
| API response → UI | UI displays status but cannot promote capability. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-14 | Spoofing | capability routes | mitigate | Reuse single-owner server admission for GET and POST. |
| T-01-15 | Tampering | proof POST | mitigate | Same-origin, intent, one-time CSRF, fixed body, server-generated scope/data. |
| T-01-16 | Information disclosure | API/UI denial | mitigate | Neutral response/render and minimized evidence; remove email. |
| T-01-17 | Elevation | disabled controls | mitigate | Native disabled attributes and no owning routes/effect handlers. |
| T-01-18 | Repudiation | proof mutation | mitigate | D1 audit record binds actor digest, workspace, operation, outcome, and evidence reference. |
</threat_model>
