<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> knowledge handler | Untrusted identity locators and command bodies cross into owner-only authority. |
| Source/proposal -> React UI | Untrusted text must remain escaped data and never control markup or authority. |
| Knowledge drift -> future artifact projection | Dependency evaluation must not over-pause or under-contain unrelated artifacts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05 | Tampering | interview snapshot and decision races | mitigate | Block on exact digest/revision/unique-guard tests for retry, response loss, stale tabs, and concurrent operations. |
| T-02-06 | Spoofing / Elevation | knowledge handler | mitigate | Owner admission first, origin/fetch/intent/CSRF/body checks, closed commands, gate row, neutral denial, and zero-delta negatives. |
| T-02-07 | Tampering | drift traversal/replacement activation | mitigate | Persist sorted reached edges and impact digest; require a second exact-digest activation transaction. |
| T-02-08 | Information Disclosure | knowledge UI | mitigate | Escaped JSX text only, neutral unauthorized render, malformed-response authority hiding, and no private data in error projections. |
| T-02-SC | Tampering | npm installs | mitigate | This plan installs nothing; Plan 03 is the blocking legitimacy checkpoint. |
</threat_model>
