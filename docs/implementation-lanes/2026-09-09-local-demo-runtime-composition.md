# LOCAL_DEMO runtime composition track

**Status:** explicitly unaccepted local candidate; no plan or phase credit.

This track permits owner-facing local runtime composition over fictional,
disposable data only. Every adapter is effect-free and fake or reject-only.
It may exercise wiring, rendering, fail-closed behavior, and local operator
journeys, but may not select or contact a provider, use credentials, read real
prospect/contact data, persist hosted state, schedule work, create or deliver
exports, send mail, place calls, or restore an external system.

It is an implementation label, not an acceptance gate. Local journeys, tests,
fixtures, digests, and UI availability demonstrate local contribution only;
they cannot satisfy hosted, provider, real-data, recipient, owner-acceptance,
or zero-effect checkpoints and cannot create a plan summary.

Composition remains behind the existing development/loopback and owner-
admission boundary. Production bundles and Cloudflare identity mode must not
reach `LOCAL_DEMO`. Fictional identities and disposable data must be labelled,
and any absent real prerequisite remains disabled or rejects by default.

This track does not change plan dependencies, completion counts, roadmap status,
or the external-effect boundary.
